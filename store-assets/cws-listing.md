## Description

Apify Console shows Insights one month at a time and one Actor at a time. If you run dozens or hundreds of Actors, answering "which ones lost users this quarter?" means a lot of clicking. Insights Plus adds the missing views to the pages you already use.

IN THE CONSOLE

• Monetization: pick any range of months or use the 1m, 3m, 6m and 1y shortcuts, group by day, week or month, and click a day to see which Actors earned or ran that day.
• Range export: one JSON file for the selected months, in the same shape as the Console's monthly export.
• Actor portfolio: every Actor ranked by revenue, with month-over-month change.
• Acquisition triage: users, referrers and countries for all Actors in one table, with the Actors losing or gaining users called out.
• Actor quality inbox: every Actor's quality score, setup checks and suggested fixes in one list.
• Today list: the to-dos from Acquisition and Quality in one place.
• Run success overview: the success rate of every Actor, and its user runs.
• Not public filter: show only your private Actors on My Actors.

Each Insights page keeps an Original / Plus switch, so the built-in view is always one click away.

ON PUBLIC PAGES

• Actor pages: active users and runs for the last 30 days, total runs, created date and last run.
• Builder profiles: sort Actors by runs, monthly active users, users or bookmarks, and filter with thresholds such as "MAUs at least 10".
• Builder benchmark: see how a builder ranks among public builders, from a daily snapshot of public profile data.

Turn any feature off in the popup.

YOUR DATA STAYS IN YOUR BROWSER

The extension reads the analytics your Console session can already see and caches them on your computer for a few minutes. It sends nothing to the developer, runs no analytics or tracking, and needs one permission: storage. Your Apify token stays inside the Console page. The extension's other code never receives it.
